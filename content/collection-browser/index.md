# IIIF-Sammlungs-Browser

Der Inhalt von Projektemacher.org lässt sich auch als [IIIF-Sammlung](https://iiif.io/api/cookbook/recipe/0032-collection/) betrachten. Der folgende Browser listet die Blogs und deren Bilder auf, ein Klick auf einen Eintrag öffnet ihn im Betrachter. Der Sammlungs-Browser nutzt [Mango](https://github.com/Mango-IIIF/Mango) — Viewer und Collection Navigator.
